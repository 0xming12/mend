mend is one patch tool for every AI edit format: it applies unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON tool-call edits to a tree of text files, matching lines even when whitespace or indentation drifted, and changing every file or none.

## Run it

```sh
node main.ts [PATCH]
```
